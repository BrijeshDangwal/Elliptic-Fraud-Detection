# Data

The Elliptic dataset is not stored in this repository. Download it from Kaggle:

https://www.kaggle.com/datasets/ellipticco/elliptic-data-set

Unzip it into `data/raw/`, so that these three files sit somewhere under that folder:

```
elliptic_txs_features.csv
elliptic_txs_classes.csv
elliptic_txs_edgelist.csv
```

The loader searches subfolders, so the folder structure inside the Kaggle zip does not matter.
